# Security policy

## Supported versions

Only the latest release of Breccia gets security fixes. Update to the latest release before you report a problem.

## Report a vulnerability

Please report it privately with GitHub's private vulnerability reporting: open the
[Security tab](https://github.com/EightBitBoy/breccia/security) of the repository and choose "Report a vulnerability".

Say what you found, which version of Breccia you used, and the steps to see it. A short note is enough.

## What not to put in a public issue

Do not open a public issue or pull request for a vulnerability, and do not post details of it anywhere public until it
is fixed. Do not attach your own notes, or anyone's, to a report. If a note is needed to show the problem, make a
small example.

Problems that are not vulnerabilities (a bug, a crash, a wrong result) belong in a normal issue.
