Breccia

Breccia is a notes app where the fragments of everyday work and tasks bind into one body of knowledge.

Download for Windows

Newest release on GitHub · Windows only for now

What it is

Breccia is a local-first outliner for the desktop: a lean, personal take on Logseq. You write in a daily journal and in pages, as nested bullets. Any bullet can be a task, and every task in every file shows up as a card on a Kanban board. Your notes stay plain Markdown files in a folder you choose; there is no account or server, and your notes are not kept in a database.

It is made for one person who keeps daily notes and tasks in one place and wants to own the files.

Features

Journal

One file per day, shown as a scrolling feed with today on top. Jump to any date by typing it into search (12 Mar, yesterday) or with the date picker next to "Journal" (Ctrl Shift D), including days without an entry.

Pages, links and tags

Pages with [[links]] and #tags. Each page lists its linked references: every block elsewhere that links to it. The sidebar's Tags section lists every tag with the number of blocks that have it; a tag can be renamed there.

Page colors

Give a page one of 25 colors, and the journal's blocks that link to it get a faint wash of it.

Tasks and Kanban boards

A block starting with a state keyword (TODO, DOING, DONE, …) is a task. The states are configurable, and Ctrl Enter cycles through them (Ctrl Shift Enter removes the state). A task records when it got its state, and a finished one shows when it was done and how long it took.

Kanban boards cover every task block in the folder: each column shows the tasks in one state. Dragging a card to another column changes the state in its file; dropping it at a place in a column keeps that place. Archiving a card hides it from the board and keeps its state. Finished tasks done more than 14 days ago are archived by themselves, and Archive in the sidebar lists every archived task.

Git sync

If the folder is a Git repository, Breccia commits your changes a few minutes after you stop typing, and pulls and pushes when it has a remote. The history button next to the Git item in the status bar lists the folder's commits, newest first.

Six themes

Light, Dark, Violet, Graphite, Taupe and Teal, plus System, which follows Windows.

Graph

A graph of the pages and the links between them.

Local-first, plain Markdown

On first start, Breccia asks for a notes folder: open an existing one or create a new one. Everything lives there:

notes/
  journals/2026-10-29.md   one file per day
  pages/Project X.md       one file per page
  breccia/config.toml      task states, boards and other settings

Every file is plain Markdown, so you can read and edit your notes in any text editor, back them up as you like, and keep them in Git. Breccia never reformats text you wrote; it only saves line endings as LF.

  • The notes format describes the folder and the files exactly, for anyone who wants to write a compatible app.
  • Breccia, Obsidian and Logseq compares the three and says how to open a Breccia folder in Obsidian or Logseq.

Keyboard-driven

F1 shows every keyboard shortcut in an overlay, grouped, with a filter. Ctrl K searches page names and block text, with #tag and state filters. Ctrl Enter cycles a task's state, and Alt ← / Alt → go back and forward between views.

And more: All pages (a table of every page, to sort and filter), zoom for the whole window, and a tray icon on Windows so Breccia is always at hand.

Install

Breccia runs on Windows only for now.

  1. Open the Releases page of the GitHub repository.
  2. Download Breccia_X.Y.Z_x64-setup.exe from the newest release and run it. It installs for the current user only, with no admin prompt, and adds a Start-menu entry.
  3. The installer is not code signed, so Windows SmartScreen warns on the first run. Click "More info", then "Run anyway".

Breccia needs Microsoft WebView2, which Windows 11 already has. If it is missing, the installer downloads it, so the first install needs an internet connection.
